# Second Nature 0.7.0 (unreleased)

- **New mod ID:** the mod ID is now `SecondNature`. Saves and servers made before 0.7.0 keep working with the old ID, `AutoMindful`, which the Workshop item still carries as "Second Nature (legacy ID: only for saves made before 0.7.0)", and are told once how to switch. Settings, logs and progress carry over, a save with both enabled runs the mod once, and new saves only need Second Nature.
