# AutoMindful 0.1.23

When several remembered fixtures are usable, scouting can compare the outbound and return walking time of completed trips from the same training tile. Nearby usable options still come first. If the nearest known fixture has no comparable time, scouting keeps the distance-based choice. Timing excludes the care action and queue waits; trips with failures, pauses or different game speeds are not timed. Every selection still rechecks the actual fixture, permission, range and floor. No routes or locations are saved across game sessions.
