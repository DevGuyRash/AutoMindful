# Second Nature 0.4.0

- **New name:** AutoMindful is now **Second Nature**, and Recovery is now **Autopilot**. The mod ID stays `AutoMindful`, so saves, settings, logs and key bindings carry over.
- **Lifestyle is optional:** without Lifestyle: Hobbies, Autopilot still eats, drinks, rests, bandages and watches supplies; right-click your survivor to start it. Yoga and Meditation say they need Lifestyle instead of failing.
- **Autopilot cooks:** when only raw food is left, it cooks it on a powered stove or oven nearby, stays with it, takes it out once cooked or before it burns or if the power goes, turns the stove off and eats. Raw food that would spoil soon cooks in the same batch (up to four dishes, each taken out when done), and cooked leftovers go into a powered fridge. It never borrows a stove that is on or holds someone else's food, never goes to bed with the stove on, and Stop turns off a stove it lit. Option: **Autopilot: cook raw food on a stove**.
- **Fix:** starting a job no longer reads Lifestyle's Yoga skill directly, which broke Autopilot when Lifestyle was missing.
