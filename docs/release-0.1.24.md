# AutoMindful 0.1.24

- Retries an unexpectedly interrupted or unstarted meditation or yoga action without rearming the session. Train both keeps an eligible interrupted exercise and alternates after completed practice.
- Preserves unrelated work, the current training tile, and exact-origin returns. Explicit Stop, genuine movement, danger and completion are not retried.
- A lingering run or sprint animation flag alone no longer ends training. Real run/sprint input still does, even if it cancels the native action before the next tick.
