# AutoMindful logo

Generated with the built-in image generation tool. The selected artwork is saved as [logo.png](logo.png); [preview.png](preview.png) is the 256 × 256 Workshop export. The preview is also used in the repository README. The export only resamples the selected artwork and removes metadata; it does not redraw it.

## Initial generation prompt

```text
Use case: logo-brand.
Asset type: square production logo and Steam Workshop thumbnail for the Project Zomboid mod AutoMindful.
Primary request: Create a new original, polished identity for AutoMindful, which automatically practices yoga and meditation while taking care of the survivor's basic needs.
Subject: one strong, elegant emblem combining an unmistakable seated cross-legged meditation silhouette with a single circular repeat-arrow motif. Make the automation and mindfulness feel like one coherent symbol, not separate clip-art icons.
Style/medium: crisp graphic illustration, flat vector-like shapes, careful negative space, restrained subtle print texture. Calm and sturdy, fitting a survival-game mod rather than a glossy wellness app.
Color palette: use the existing identity's dark charcoal forest background, warm ivory and muted sage, with a restrained warm golden accent if it improves hierarchy.
Composition/framing: square 1024 by 1024 artwork, centered emblem in the upper two thirds, generously padded. A bold clean wordmark underneath. Design must remain legible when exported to 256 by 256 pixels.
Text (verbatim): "AutoMindful". This is the only text. Spell A-u-t-o-M-i-n-d-f-u-l exactly, with capital A and M.
Constraints: one finished logo tile, no mockup or presentation sheet, no tiny tagline, no border cropping the emblem, no extra text, no watermark, no gore, no copied trademarks, no 3D bevels, no photorealism. Opaque background. Strong silhouette and deliberate typography, balanced professional composition.
```

## Final editing prompt

The initial generated image was the edit target.

```text
Use case: logo-brand.
Input image: edit target, the newly generated AutoMindful logo.
Simplify this logo for a small Steam Workshop thumbnail. Remove the five small surrounding resource symbols (sleeping bed and Z letters, fork and knife, water droplet, heart, battery) and the inner dashed ring and radiating marks. Retain the centered meditating survivor as the single subject, enlarge the survivor to use the interior of the circular repeat-arrow emblem gracefully, and leave generous negative space. Retain the rugged flat illustration, sage repeat-arrow loop, dark forest background, warm ivory figure, and the bold exact "AutoMindful" wordmark. Keep a balanced square layout with the whole wordmark comfortably inside the canvas. No additional symbols, no extra text, no watermark. This is one finished production logo, not a mockup.
```
