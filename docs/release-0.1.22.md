# AutoMindful 0.1.22

Scouting learns successful fixed toilets, places to wash, and clean drinking sources for the current survivor's game session. A trip earns a place in memory only after native care is confirmed and the survivor returns to the exact training tile. Nearby usable sources come first; otherwise a remembered fixture is considered only within the configured radius and on the same floor, using a fresh local lookup and the usual permission and care checks. A missing, changed or occupied fixture cannot replace the active trip's exact target. No stored paths, saved coordinates outside the session, portable loot or vehicle targets.

The scout also distinguishes real vanilla path failure from a player cancellation on stock object and vehicle routes. A genuine failed route can return safely and skip the blocked option; player input, danger, and original-spot return rules remain unchanged. The game controls pathfinding.
